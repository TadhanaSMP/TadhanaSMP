# QA report

Checked 11 October 2026. This report separates local source/build/browser evidence from deployment and integration work that requires the owner’s real configuration. The delivery is a complete source package for manual GitHub and Vercel setup, not an already deployed production service.

## Delivered implementation

The replacement includes 16 public pages, three permanent legacy redirects, a published-only news detail route, all eight original API paths, and the new status endpoint. README.md lists the routes. src/app contains page layouts and metadata; src/components holds the gallery, dialogs, edition/rank tabs, clipboard, status and verification controls. src/config and src/data hold editable public information. src/lib, src/app/api and prisma contain the hardened integration boundary and additive database changes. The scripts and nine owner guides cover maintenance, verification, credential rotation, and deployment.

The homepage uses the supplied wordmark, five approved brand colors, restrained orbit/glow effects, and eight distinct real community scenes. The gallery has 16 curated screenshots, descriptive captions, combined search/category filtering, a largest-available-image lightbox, buttons, keyboard arrows, Escape, and touch handlers. Missing server facts, products, dates, player counts, and rank requirements are not invented. Rules and legal pages remain explicit review drafts.

## Browser layout evidence

Cloud Chrome checked every public route at 320, 375, 390, 430, 768, 1024, 1440 and 1920 CSS pixels: 128 distinct route/width checks, zero recorded failures. The machine-readable observations are in responsive-qa-results.json. Tests used a same-origin iframe with exact CSS viewport dimensions, loaded styles, document/client/scroll widths, page headings, loaded image health and visible content bounds. A normal vertical scrollbar reduces the available client width; internal rank tabs and the narrow cookie table intentionally scroll within their own containers.

An orbit decoration’s overflow was corrected at its source, and the homepage was retested at all eight widths. Mobile lightbox captions were restored and checked at 320px: the 300px dialog had equal client/scroll widths and a visible caption. This is desktop browser viewport testing, not physical phones or tablets. No Lighthouse, CrUX, LCP, INP or CLS score is claimed.

Gallery/rank/dialog/clipboard interactions were checked in an optimized production preview. Later clipboard-feedback, unique cookie-label and caption fixes were checked again in the development preview. The workspace hostname is explicitly allowed only for Next development tooling. That preview required a restart during QA; successful interactions were repeated after recovery. The final release build and HTTP smoke use production frame denial and other normal security settings. No temporary framing/eval relaxation is included in production.

The browser did not expose OS-level reduced-motion emulation or physical-device testing. Source review confirms CSS disables animations/transitions/smooth scrolling, and the Motion component bypasses/reveals content for the reduced-motion preference and reacts to changes. Verify that behavior with a real OS preference, keyboard/assistive technology and representative devices before launch. Token contrast tests meet normal-text AA targets for the actual configured text/CTA pairs; this is not WCAG certification. Browser console capture also includes extension errors and is not a complete cross-frame production observability audit.
