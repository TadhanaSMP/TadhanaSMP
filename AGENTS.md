# Project guidance

Read the relevant installed Next.js documentation in `node_modules/next/dist/docs` before framework edits. This project uses Next.js 16 App Router; cookies and dynamic route parameters are asynchronous.

Use npm and the checked-in package-lock.json. Keep private environment files, credentials, databases, build artifacts, and node_modules out of exports. Do not enable authentication or publish store prices without approved configuration and staging verification. Read docs/CONTENT_AND_CONFIG_GUIDE.md and docs/SECURITY_AUDIT_AND_SECRET_ROTATION.md before changing integrations.
